How it works
  • One run is created per model name, all using the same benchmark and configuration.
  • All runs are tagged with a shared bulk_<id> tag so you can filter them together from the runs list.
  • Runs start immediately in background threads — you can watch their progress from the runs list.
  • After completion, use Compare to see side-by-side results.
