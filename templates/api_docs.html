REST API Documentation

Programmatically control benchmarks, runs, and results.

Base URL: {{ request.scheme }}://{{ request.get_host }}/api/v1/

All endpoints return JSON. POST / DELETE bodies must use Content-Type: application/json. No authentication required on this local deployment. Paginated responses include total, limit, offset, returned fields.

Benchmarks

GET /api/v1/benchmarks/ List benchmarks

Returns all benchmarks. Filter with loaded=1 (only loaded), category=knowledge. Paginated with limit / offset.

curl example:

curl "{{ request.scheme }}://{{ request.get_host }}/api/v1/benchmarks/?loaded=1&limit=20"

Example response:

{
  "benchmarks": [
    {
      "id": 1,
      "slug": "mmlu",
      "name": "MMLU",
      "description": "Massive Multitask Language Understanding",
      "category": "knowledge",
      "num_questions": 14042,
      "is_loaded": true,
      "loaded_at": "2024-01-15T10:30:00Z",
      "metadata": {}
    }
  ],
  "total": 8, "limit": 200, "offset": 0, "returned": 8
}
GET /api/v1/benchmarks/{slug}/ Benchmark detail

Full benchmark details including all distinct subjects.

curl example:

curl {{ request.scheme }}://{{ request.get_host }}/api/v1/benchmarks/mmlu/

Example response:

{
  "id": 1, "slug": "mmlu", "name": "MMLU",
  "category": "knowledge",
  "num_questions": 14042, "is_loaded": true,
  "metadata": {},
  "subjects": [
    "abstract_algebra", "anatomy", "astronomy", ...
  ]
}
GET /api/v1/benchmarks/{slug}/questions/ List questions

Paginated questions. Filter with subject, difficulty. Includes choices for MCQ and context for RAG benchmarks.

curl example:

curl "{{ request.scheme }}://{{ request.get_host }}/api/v1/benchmarks/mmlu/questions/?subject=anatomy&limit=5"

Example response:

{
  "questions": [
    {
      "question_id": "0",
      "question": "What is the powerhouse of the cell?",
      "subject": "anatomy",
      "difficulty": "easy",
      "correct_answer": "A",
      "choices": {
        "A": "Mitochondria", "B": "Nucleus",
        "C": "Ribosome",    "D": "Golgi"
      }
    }
  ],
  "benchmark": "mmlu",
  "total": 135, "limit": 100, "offset": 0, "returned": 5
}

Runs

GET /api/v1/runs/ List runs

Paginated run list. Filter with status (pending / running / completed / failed / cancelled), benchmark (slug), model (partial), tag (partial).

curl example:

curl "{{ request.scheme }}://{{ request.get_host }}/api/v1/runs/?status=completed&benchmark=mmlu&limit=10"

Example response:

{
  "runs": [
    {
      "id": 42, "benchmark": "mmlu",
      "benchmark_name": "MMLU",
      "provider": "openai", "provider_name": "OpenAI",
      "model_name": "gpt-4o", "status": "completed",
      "score": 87.3, "total_questions": 100,
      "correct_answers": 87, "progress_pct": 100,
      "temperature": 0.0, "max_tokens": 512,
      "tags": "baseline",
      "created_at": "2024-01-15T10:00:00Z",
      "completed_at": "2024-01-15T10:12:00Z",
      "duration_seconds": 720.5
    }
  ],
  "total": 53, "limit": 50, "offset": 0, "returned": 50
}
POST /api/v1/runs/ Create & start a run

Creates a new run and starts it in the background. Returns the run object with status: "pending".

Request body:

{
  "benchmark":        "mmlu",    // slug (required)
  "provider":         "openai",  // slug (required)
  "model_name":       "gpt-4o",  // required
  "num_questions":    100,       // 0 = all
  "temperature":      0.0,
  "max_tokens":       512,
  "system_prompt":    "",
  "parallel_workers": 4,
  "few_shot_count":   0,
  "use_cot":          false,
  "tags":             "api,automated",
  "notes":            "Nightly eval",
  "webhook_url":      ""
}

curl example:

curl -X POST \
  {{ request.scheme }}://{{ request.get_host }}/api/v1/runs/ \
  -H "Content-Type: application/json" \
  -d '{
    "benchmark": "mmlu",
    "provider": "openai",
    "model_name": "gpt-4o",
    "num_questions": 50
  }'

Response (201):

{
  "id": 43, "benchmark": "mmlu",
  "model_name": "gpt-4o",
  "status": "pending", "score": 0.0, ...
}
GET /api/v1/runs/{id}/ Run detail

Full run object. Add ?subjects=1 to include per-subject accuracy breakdown in a subject_stats field.

curl example:

curl {{ request.scheme }}://{{ request.get_host }}/api/v1/runs/42/?subjects=1

Example response:

{
  "id": 42, "benchmark": "mmlu",
  "model_name": "gpt-4o",
  "status": "completed", "score": 87.3,
  "subject_stats": {
    "anatomy":   {"total": 14, "correct": 13, "pct": 92.9},
    "astronomy": {"total": 10, "correct": 8,  "pct": 80.0}
  }
}
GET /api/v1/runs/{id}/status/ Run status (polling)

Lightweight endpoint for polling run progress. Returns status, score, answered count, and progress percentage.

curl example:

curl {{ request.scheme }}://{{ request.get_host }}/api/v1/runs/42/status/

Example response:

{
  "id": 42, "status": "running",
  "score": 71.2, "total_questions": 100,
  "correct_answers": 51, "answered_count": 71,
  "progress_pct": 71, "duration_seconds": 35.2,
  "error_message": null
}
POST /api/v1/runs/{id}/cancel/ Cancel a run

Cancels a pending or running run. Returns 400 if already completed or failed.

curl example:

curl -X POST {{ request.scheme }}://{{ request.get_host }}/api/v1/runs/42/cancel/

Example response:

{"cancelled": true, "id": 42}
GET /api/v1/runs/{id}/results/ Run results

Paginated per-question results. Filter with correct=true / false, subject=anatomy.

curl example:

curl "{{ request.scheme }}://{{ request.get_host }}/api/v1/runs/42/results/?correct=false&limit=20"

Example response:

{
  "results": [
    {
      "id": 1201,
      "question_id": "mmlu_42",
      "question": "Which is NOT a type of blood cell?",
      "subject": "anatomy", "difficulty": "medium",
      "correct_answer": "C",
      "model_response": "I think the answer is B...",
      "parsed_answer": "B", "is_correct": false,
      "response_time": 0.82,
      "tokens_input": 124, "tokens_output": 12,
      "estimated_cost": 0.000041
    }
  ],
  "run_id": 42,
  "total": 13, "limit": 20, "offset": 0, "returned": 13
}
DELETE /api/v1/runs/{id}/delete/ Delete a run

Permanently deletes the run and all its results. Returns 404 if not found.

curl example:

curl -X DELETE {{ request.scheme }}://{{ request.get_host }}/api/v1/runs/42/delete/

Example response:

{"deleted": true, "id": 42}

      "default_model": "gpt-4o", "base_url": null

    {

      "provider_type": "ollama", "is_active": true,
      "default_model": "llama3.1:8b",
      "base_url": "http://localhost:11434"

  "count": 2
}

Leaderboard

Best score per (benchmark, model_name) pair, ordered by benchmark then score. Filter with benchmark (slug). Max limit=1000.

curl example:

curl "{{ request.scheme }}://{{ request.get_host }}/api/v1/leaderboard/?benchmark=mmlu"

Example response:

{
  "leaderboard": [
    {
      "benchmark": "mmlu",
      "benchmark_name": "MMLU",
      "model_name": "gpt-4o",
      "provider": "openai",
      "score": 87.3,
      "correct_answers": 87,
      "total_questions": 100,
      "run_id": 42,
      "completed_at": "2024-01-15T10:12:00Z"
    }
  ],
  "count": 5
}
