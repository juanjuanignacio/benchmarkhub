How RAG Benchmarking Works

Each row in your CSV maps to one benchmark question with its own context passage:

  1. The platform sends the model a prompt containing the context + question.
  2. The model answers based on the provided passage.
  3. The answer is compared to correct_answer using normalised word-boundary matching.
  4. Use | in correct_answer to define multiple valid answer aliases.
